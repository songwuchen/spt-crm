# SPT-CRM 服务器部署指南

CI 负责测试并推镜像到 Harbor；服务器上**手动**拉镜像启动即可（无自动化部署脚本）。

## 一、服务器信息

| 项 | 值 |
|----|----|
| SSH | `ssh songwuchen@192.168.0.39` |
| 部署目录 | `/home/songwuchen/spt-crm` |
| Harbor | `wmharbor.fourier.net.cn:39011/songwuchen` |
| HTTP | `http://192.168.0.39:39280` |
| HTTPS | `https://192.168.0.39:39281`（需证书） |
| PostgreSQL | 宿主机 `5439` → 容器 `5432` |
| 默认登录 | 用户名 `admin` / 密码 `admin123`（首次登录后请立刻修改） |

镜像：

- `.../songwuchen/spt-crm-backend:latest`
- `.../songwuchen/spt-crm-frontend:latest`
- `.../songwuchen/redis:7-alpine`
- `.../songwuchen/pgvector:pg16`

## 二、上传部署文件

把下面文件放到服务器 `~/spt-crm/`：

| 文件 | 说明 |
|------|------|
| `docker-compose.prod.yml` | 编排（服务器上可改名为 `docker-compose.yml`） |
| `nginx.prod.conf` | 前端 Nginx |
| `.env.example` | 环境变量模板 |

本机示例：

```powershell
scp docker-compose.prod.yml nginx.prod.conf .env.example songwuchen@192.168.0.39:~/spt-crm/
```

服务器上：

```bash
ssh songwuchen@192.168.0.39
cd ~/spt-crm
mv docker-compose.prod.yml docker-compose.yml   # 首次
```

## 三、配置 `.env`（首次）

```bash
cd ~/spt-crm
cp .env.example .env
chmod 600 .env
nano .env
```

至少改：

```env
POSTGRES_PASSWORD=强密码
JWT_SECRET_KEY=长随机串
CORS_ORIGINS=http://192.168.0.39:39280,https://192.168.0.39:39281
```

## 四、登录 Harbor 并启动

```bash
cd ~/spt-crm
docker login wmharbor.fourier.net.cn:39011

docker compose --env-file .env -f docker-compose.yml pull
docker compose --env-file .env -f docker-compose.yml up -d
docker compose --env-file .env -f docker-compose.yml ps
```

访问：http://192.168.0.39:39280

| 用户名 | 密码 | 说明 |
|--------|------|------|
| `admin` | `admin123` | 系统管理员（演示默认值，**登录后请立刻修改**） |

> 首次空库启动后，需执行一次 seed 才会有上述账号：  
> `docker compose --env-file .env -f docker-compose.yml run --rm backend python -m scripts.seed --production`

> 证书：compose 挂载 `/etc/letsencrypt`。没有证书时先注释 `frontend` 里证书 volume 和 `39281`，只用 39280。

## 五、日常升级

CI 推完新镜像后，在服务器：

```bash
cd ~/spt-crm
docker compose --env-file .env -f docker-compose.yml pull
docker compose --env-file .env -f docker-compose.yml up -d
```

若本次有数据库结构变更，再执行：

```bash
docker compose --env-file .env -f docker-compose.yml run --rm backend alembic upgrade head
```

## 六、常用命令

```bash
cd ~/spt-crm
dc='docker compose --env-file .env -f docker-compose.yml'

$dc ps
$dc logs -f --tail=200 backend
$dc restart backend
$dc down
```

## 七、相关说明

- 生产镜像走私有 Harbor，机器访问不了 Docker Hub 属正常。
- 端口：`39280` HTTP / `39281` HTTPS / `5439` PG，已与同机其他项目错开。
- 该机容器较多，拉镜像时建议用 `tmux`，避免 SSH 会话中断。
